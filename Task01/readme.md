# Лабораторная работа Task01

В данной папке содержатся выполненные задания:

ratings.csv — файл, содержащий оценки пользователей. Содержит столбцы: userId (идентификатор пользователя), movieId (идентификатор фильма), rating (оценка) и timestamp.
movies.csv — справочник фильмов (содержит идентификатор, название и жанры).
ratings_count.txt — результаты подсчета минимального и максимального ID пользователей.
sqlite.txt — информация об установленной версии СУБД SQLite и режимах вывода.
